Design and Documentation of a College Department Website Using HTML
Student: Chinmay T A | Roll No: 64 | Class: S7 CSEA | Subject: Web Technology / HTML | Date: 30 October 2026

1. Introduction

This report outlines the design, architecture, and standards-compliant implementation of a multi-section portal for the Department of Computer Science at FISAT Engineering College. The project focuses purely on foundational HTML5 structural markup, accessibility, and presentation design, containing the entire website within a single portable file, index.html, requiring no external dependencies, JavaScript, or server frameworks.

2. Website Architecture & Sections

The website incorporates six primary sections connected seamlessly through a sticky in-page bookmark navigation bar (<nav>):

  • Header & Navigation: Displays the department identity, institution name, vector SVG logo, and anchor jump links.
  • About the Department: Brief departmental history, mission statement, and external hyperlinks using target="_blank" and rel="noopener".
  • Academic Programmes: Core subjects presented in an unordered list (<ul>) and semester-wise roadmap in an ordered list (<ol>).
  • Faculty Directory: Structured table presenting professor credentials, designations, and research specializations.
  • Facilities: Modular overview of computing laboratories and departmental libraries encapsulated in <article> tags.
  • Student Enquiry & Contact: Interactive user admission form and institutional contact coordinates formatted via <address>.

3. HTML5 Elements & Semantic Organization

Element Category Tags Utilized Functional Purpose
Structural & Semantic <header>, <nav>, <main>, <section>, <article>, <footer> Organizes page layout logically for enhanced SEO, maintainability, and screen-reader accessibility.
Typography & Lists <h1>–<h3>, <p>, <strong>, <em>, <ul>, <ol>, <li> Maintains clear heading hierarchy, textual emphasis, and organized curriculum progressions.
Data Presentation <table>, <caption>, <thead>, <tbody>, <tr>, <th>, <td> Renders complex faculty tabular data with distinct header grouping and responsive cell borders.
Interactive Forms <form>, <input>, <label>, <select>, <textarea>, <button> Facilitates client-side input with native required, type="email", and regex pattern="[0-9]{10}".

4. Execution & Access

The application runs client-side with zero configuration:

  1. Place index.html into any folder on your machine.
  2. Double-click index.html to open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.
  3. All links, internal jumps, forms, and SVG graphics render natively in standards mode without network connectivity.

5. Conclusion

The project demonstrates how fundamental HTML5 elements and semantic markup can produce a complete, accessible, and structured college department portal. By leveraging native semantic tags and built-in form validation, the page maintains high performance, accessibility, and compatibility across all platforms.
